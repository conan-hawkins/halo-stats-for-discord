# Runtime dependencies for the bot.
#
# This file is TRACKED, unlike bot_docs/requirements.txt - `bot_docs/` is
# gitignored (see .gitignore), so that file does not survive a clone and cannot
# be relied on to build an image anywhere but the machine it already exists on.
#
# These pins are taken verbatim from `pip freeze` inside the image that is
# running in production today, so a rebuild reproduces that environment exactly
# rather than resolving something new during an infrastructure migration.
# Regenerate the same way after any dependency change:
#     docker compose exec bot pip freeze
#
# Deliberately NOT included, because they are absent from the running image too:
#   matplotlib  - social-graph plots
#   networkx    - social-graph analysis
# Both are imported lazily INSIDE functions, so the bot starts and runs without
# them; only those features raise ImportError. Adding them is a behaviour change
# and belongs in its own commit, not bundled into the containerisation.
